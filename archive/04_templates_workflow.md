# 投稿テンプレートと作業フロー

1投稿＝1ニュース。見出し・要約・出典を必ず入れる。

## スマホからOKを出す流れ（2026-11-07から）
1. 毎朝6:44に、スケジュールされたタスク「Eurogrid 毎朝の投稿案」が新しい会話で投稿案を作り、スマホに通知が届く（同じ内容は claude/daily/YYYY-MM-DD.md にも保存）
2. 運営者は通知からその会話を開き、「全部OK」「1と3だけOK」「2は〜に直して」と返信するだけ
3. その会話のClaudeが、OKの分を出す：
   - Threads：GitHubの eurogrid-posts に予約を入れる（5分後から30分おき）→ 自動で投稿
   - X：PCのChromeが開いていれば、Chromeから本文と出典の返信を投稿。閉じていれば「PCを開いたら『X投稿して』と送って」と伝え、コピーできる文を並べる
4. 運営者のOKがない案は、どこにも出さない（GitHubにも入れない）
- XはAPIが有料（2026年2月から無料枠なし。1投稿あたり約0.015ドル、リンク付きは約0.20ドル）のため、当面はChromeから投稿する。完全にPCなしにしたくなったら、X APIの有料利用（出典の返信にリンクが付くので、1日4本で月25ドル前後の目安）を検討する

## Xへの投稿のしかた（Claude用、2026-11-07に確認）
- キーボード入力（computer の type）は、日本語の最初の数文字の順番が崩れることがあるので使わない
- x.com のタブで javascript_tool から location.href='/intent/post?text='+encodeURIComponent(本文) に移動 → 約7秒待つ → aria-label「カードプレビューを削除」のボタンがあれば押す → data-testid="tweetButton" を押す
- x.com/eurogrid_jp を開き、最新の投稿の /status/数字 を取る → '/intent/post?in_reply_to=ID&text='+encodeURIComponent('出典：媒体名 URL') で同じように返信する
- 「Xでより多くの機能を利用する」（新しいアカウント向けの案内）が出たら×で閉じる。本人確認・CAPTCHA・電話番号の入力などは進めず、運営者に伝える
- 本文に「Motorsport.com」と書くとリンクになり、文字数（URL扱いで23字）も使う。140字ぎりぎりのときは注意

## 文字数とリンクのルール（X）
- 無料プランは全角140字（半角280）まで。本文は140字以内に収める
- 出典URLは本文ではなく、自分の投稿への返信（スレッド）に貼る。本文には媒体名だけ書く
- 2媒体以上を比べる投稿は、返信に出典を全部まとめる
- 返信にURLや「Crash.net」のような媒体名を書くとリンクのプレビューカードが付くことがあるので、外してから投稿する

## 作業フロー（X）
1. 収集（毎朝6:44・Claude）：情報源リストから前日〜当日のニュースを集める。日本人選手・日本メーカーの話題は優先
2. 下書き（Claude）：重要度順に並べ、テンプレートで投稿案を作る
3. 確認（運営者）：スマホで内容を見て、その会話に「OK」などと返信する
4. 投稿（Claude）：OKの分をChromeから投稿する（上の「スマホからOKを出す流れ」）
5. 振り返り（週1回）：反応の良い投稿の傾向をメモし、ルールを更新

レースウィーク（金〜日）は、セッション後の現地コメントを追加で拾う。欧州との時差は8時間（夏時間は7時間）。

## Threads
- 役割：Xに出した投稿を、ほぼそのまま転載する。新しくネタは作らない
- 出典：自動投稿では、出典（媒体名とURL）を本文に入れず、自分の投稿への返信として出す（2026-11-06決定。APIでは記事のプレビュー画像を外せないため、本文をすっきりさせる。返信側にはプレビューが付くことがある）。手動で投稿するときも同じ形にそろえる
- 文字数はXより余裕があるので、Xで削った補足を1文足してもよい
- ハッシュタグは本文に入れず、投稿画面の「コミュニティまたはトピック」で「MotoGP」を選ぶ（自動投稿では topic_tag に「MotoGP」を入れる）
- 本文に「#」を書かない（「#97」などもトピックタグになって、その後ろの文がタグ扱いで崩れる）。番号は「97番」のように書く
- 手動で投稿するときは、URLを入れると付く記事の写真つきプレビューを×で外す（コミュニティを選んだあとに再び出ることがあるので投稿直前にも確認）
- URLの末尾が「.html」だとリンクが途中で切れることがある。押して開けるか確認し、だめなら同じ内容の別記事に差し替える
- 毎朝の投稿案には、各案の下に「Threads用」の版も添える

## Instagram
- 役割：Xが速報、インスタは「じっくり読む」場所。Xで反応が良かった話題を、画像4枚前後のカルーセルにまとめ直す
- 頻度：週2〜3回（例：レース翌日の論調比較、週末前の見どころ、日本人ライダー特集）。スポンサー紹介「このロゴ、何の会社？」は毎週水曜20〜21時
- 画像：1080×1350（縦4:5）。濃紺（#0B1220）・オフホワイト（#F2EEE6）・黄色（#F5B700）の3色。フォントは英字Inter、日本語Noto Sans JP。明るい版（B）も作成済みだが、当面は濃紺（A）で統一
- 構成：1枚目＝ひと言で引きつける見出し／2〜3枚目＝中身（スペイン側・イタリア側など）／最後＝数字や事実と出典
- 写真は使わない。記事・公式・本人の写真や、MotoGPのロゴは載せない（文字とグリッド枠の図形だけで作る）
- 出典：最後の画像に媒体名と時期、キャプションにも媒体名を書く（インスタはキャプションのURLがリンクにならない）
- キャプション：2〜4行の短文＋ハッシュタグ5〜8個（#MotoGP #motogpjapan #モトGP #ライダー名 など）。「#01」のような番号もハッシュタグになるので「第1回」と書く
- 投稿時に「Threadsにもシェア」の切り替えが出たらオフ
- リール（縦型動画）の作り方は 11_video_sound.md

## 自動投稿（インスタ・Threads。2026-11-06設定。運営者がPCの前にいなくても投稿できる）
- 仕組み：GitHubの公開リポジトリ shonke1026/eurogrid-posts に投稿を入れると、GitHub Actionsが15分ごとに確認し、予約時刻を過ぎた承認済みの投稿をMeta公式のAPIで投稿する。投稿後は published.json が自動で作られる（GitHubの15分ごとの実行は遅れることがあるので、急ぐときは「Publish to Instagram」を dry_run=0 で手動実行する）
- Claudeの手順：
  1. 投稿案（インスタは画像とキャプション、Threadsは本文と出典の返信）を作り、チャットで運営者に見せる
  2. 運営者が「OK」と言ったら、posts/〈日付-名前〉/ に post.json（インスタは画像も）を入れて main に push する
     - インスタ：{"publish_at": "2026-11-11T20:00:00+09:00", "approved": true, "caption": "…", "images": ["1.jpg", "2.jpg", "3.jpg", "4.jpg"]}（画像はJPEGのみ。PNGは変換する）
     - インスタのリール（2026-11-07追加）：{"publish_at": "…", "approved": true, "caption": "…", "video": "reel.mp4"}（MP4。表紙画像を指定するときは "cover": "cover.jpg"）。フィードにも表示される
     - Threads：{"platform": "threads", "publish_at": "…", "approved": true, "text": "本文", "topic_tag": "MotoGP", "reply": "出典\n媒体名 URL"}
     - Threadsの動画（2026-11-07追加）：上の形に "video": "reel.mp4" を足す
  3. OKをもらう前の投稿は push しない（公開リポジトリなので、中身が外から見えるため）。approved が false のものは投稿されない
  4. 投稿後、published.json ができたことと、実際に出たことを確認して報告する
- 手動で試す：Actionsの「Publish to Instagram」を dry_run=1 で実行すると、投稿せずに確認だけできる。動画は check_folder に posts のフォルダ名を入れて dry_run=0 で実行すると、Metaに動画を処理させるところまでだけ行う（投稿はされない）。2026-11-07に posts/test_reel_ig と posts/test_reel_th（approved=false、2099年予約）で確認し、どちらも成功
- 声の自動作成：voice/〈回の名前〉/lines.json を置くと「Make voice」がVOICEVOXで音声を作る（11_video_sound.md）
- Xのヘッダー画像の元データ：リポジトリの assets/x_header.jpg（2026-11-07差し替え、キャッチコピー入り）
- Meta側の構成：（公開リポジトリのため省略。Project の原本を参照）
- 鍵（トークン）：GitHubのSecretsに保存（鍵はチャットに貼らない）。どちらも有効期限60日（2026-11-06発行、2027-01-05ごろ期限切れ）。毎週月曜に「Check Instagram token」が両方の動作を確認し、切れていればGitHubからメールが届く。12/28に作り直しのリマインダーあり（作り直しの手順は Project の原本を参照）
- 以前の手動フロー（インスタは画像を ドキュメント\Eurogrid\images に保存し、運営者が写真を選んでシェア。ThreadsはClaudeがChromeで入力）は、自動投稿が動かないときの予備として残す
