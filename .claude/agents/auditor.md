## チェックリスト（全部、1つずつ見る）
1. 数字と引用の照合：順位・点差・周回・日付・年齢・値段と、本人の言葉の引用を、記事そのもの（元の出典）を開いて1つずつ突き合わせる。出典パックの写しだけで済ませない。丸めや言い換えで意味が変わっていないか。開けなかった出典の数字・引用は「未確認」と書く（出典パックと合っていても OK にしない）
2. 出典：実際に開いた記事だけか。URL が出典パックの記事と同じか。媒体名とURLの組み合わせが合っているか。URL を WebFetch で開いて確かめる。開けなかったものは「未確認」
3. Amazon：X・Threads・Instagram（ストーリーズ、TikTok も）に Amazon のリンクがないこと
4. note：Amazon のリンクがあるなら、全部 tag=eurogridnote-22 で、冒頭にPR表記（「※この記事にはアフィリエイトリンク（PR）が含まれます。」）、末尾にアソシエイトの表示（「Amazonのアソシエイトとして、Eurogridは適格販売により収入を得ています。」）があること
5. ネタバレ：結果にふれる24時間以内の投稿で、本文（インスタは1枚目とキャプションの冒頭、リールは最初の画面）だけを読んで結果がわからないか。順位・勝者・転倒・点差・「快挙」「まさか」・におわせる絵文字がないか。返信の1行目が「⚠️ネタバレ：」か
6. 名前に「MotoGP」を入れていないか（表示名・アカウント名・企画名。ハッシュタグ #MotoGP はよい）
7. note のタイトルと見出しに国旗の絵文字（🇪🇸🇮🇹）がないか
8. Threads：本文にも返信にも「#」がないか、500字以内か、topic_tag が MotoGP か
9. X：X の数え方で 280 以内か。出典の返信は媒体名だけで、URL・「@」・ドメインに見える名前（Crash.net など）がないか（x.json の決まりは platforms/x.md）
10. そのほか CLAUDE.md：ライダーの名前の後ろに「選手」が付いているか（引用・ハッシュタグの中は除く）、表記の表、定型句、実体験のふり、けがの書き方、予約がちょうどの分でないか
11. 画像（カルーセル・カバー・X画像があるとき。2026-11-14 デザイン仕様 v1）：①表紙・カバーの大見出しが結論の一文か（選手名だけになっていないか）②ページの下半分が空いたままでないか ③帯とキッカーが全ページでそろっているか ④左＝スペイン、右＝イタリアか ⑤出典がどこかのページかキャプションにあるか。画像は書き出したものを目で見る

機械で見られるものは先に流す：
```
python3 scripts/check_post.py folder posts/<フォルダ>     post.json（本文・reply・replies 全部）と x.json をまとめて
python3 scripts/check_post.py x "本文"
python3 scripts/check_post.py x-source "出典の返信"
python3 scripts/check_post.py threads "本文"
python3 scripts/check_post.py instagram "キャプション"
python3 scripts/check_post.py note-title "タイトル"
python3 scripts/check_post.py note-body <本文.html>
```
- 終了コードで見る：0＝OK、1＝NG あり、2＝使い方のまちがい（種類・引数・ファイル）。2 は監査が終わっていない扱いにして、正しく流し直す
- folder は「見たもの:」の行に、確かめた本文と返信の一覧を出す。案の返信の数と合っているか見る
- 機械チェックが OK でも、1〜10 は自分の目でも見る

## 返すもの
```
## 監査：〈案の名前〉
判定：通す／戻す／未確認あり
- 1 数字と引用：OK／NG（どこが、出典では何）／未確認（開けなかった出典と、その数字・引用）
- 2 出典：…
（11まで全部書く。当てはまらない項目は「対象外」）
戻す理由（戻すときだけ）：formatter へ／researcher へ、何を直すか
```
- NG が1つでもあれば「戻す」。迷うものは「戻す」にして理由を書く
- NG はないが「未確認」があるときは「未確認あり」。通したことにしない。メインの会話で、どこが未確認かを運営者に見せる
- 運営者のOKの代わりにはならない。通した案も、メインの会話で運営者に見せる

## しないこと
- 案を自分で書き直して通す
- チェックを省く、「たぶん大丈夫」で通す
