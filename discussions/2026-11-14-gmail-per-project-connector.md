# プロジェクト単位でコネクタ（Gmailの読み先）を変えられるか

状態： Claude回答済み

## 素材

- 運営者からの質問（2026-11-14）：プロジェクト単位でコネクト（コネクタ）を変えられないか
- 経緯：アカウント統一の相談で「ClaudeのEurogrid側の読み先を eurogrid.jp 本体へ」が運営者の計画。同時接続の可否確認（2026-11-14-gmail-dual-connection-check）で、Claudeからは「いまの環境では2つ目は持てていない。タスクごとに選べるのか既定が1つなのかは読み取れない」と未確認のまま残った
- その後、運営者が claude.ai の設定画面を実測した：Gmail コネクタは1件のみで、アカウントの追加・切り替えの項目はない（詳細画面の操作は「切断」のみ）。コネクタ自体が持てる Google アカウントは1つ、という点は確定している
- 残っている論点は「コネクタの使い分けの単位」。受け口（定期タスク）がプロジェクトやルーティンごとにまとまっているなら、その単位で使うコネクタや読み先を変えられる余地がないか
- この相談は Claude 宛てのみ。チャッピーは回答不要
- 合言葉は「プロジェクト」
- 運営者はこの合図のあと、手動起動をしません

## 質問票（ユーロ）

- Q2. Eurogrid側の受け口と tri-council側の受け口で、違う Gmail の読み先を使い分けることはできますか。できる場合は、必要な設定変更を、あなた側でできることと運営者の操作に分けて書いてください

## Claude回答

### 2026-11-14 01:58（即時の受け口）

合言葉：プロジェクト

- Q1. 単位は「定期タスク（旧名ルーティン）1つずつ」です。プロジェクト単位ではありません。Claude Code の公式ドキュメント（code.claude.com/docs/en/routines）では、定期タスクは「プロンプト、リポジトリ、コネクタのセット」を保存したもので、作成・編集画面の Advanced settings の Connectors タブで、タスクごとにコネクタを外したり足したりできます（初期値は接続済みの全部が入る）。プロジェクトから作ったタスクはプロジェクトの画面に並びますが、プロジェクト単位でコネクタを選ぶ設定は、ドキュメントには見当たりません（未確認）。即時の受け口と1時間ごとの受け口がどうまとめられているかは、この実行の中からは見えません（わからない）。
- Q2. いまの作りのままでは、Gmail の読み先をタスクごとに変えることはできないと考えます。タスクで選べるのは「どのコネクタを使うか」までで、コネクタは claude.ai アカウントに1つずつ紐づいているためです。使い分けたいなら、現実的な順に次の3つ。
  1. メール側で寄せる（いまのやり方）：eurogrid.jp に届く合図を、コネクタがつながっている側の受信箱に転送する。設定は運営者（Gmail の転送とフィルタ）。Claude 側は検索の条件を変えるだけで済む
  2. 別の Gmail 用コネクタを「カスタムコネクタ」として足し、タスクごとにどちらを入れるか選ぶ。足すのは運営者（claude.ai/customize/connectors）、タスクの Connectors タブで入れ替えるのも運営者。2つ目の Gmail を足せるかは未確認
  3. claude.ai のアカウントを分け、tri-council 側のタスクを別アカウントに作る。コネクタもタスクもアカウントごとなので確実に分かれるが、利用枠や管理が2つになる
  Claude 側でできるのは、受け口の指示文（検索条件など）の案を書くことだけです。タスクの設定変更は、このタスクの決まりでやりません。
- Q3. おおむね合っています。根拠は2つ。ドキュメントで「コネクタはタスクごとに入れる・外すを選ぶ」「コネクタは claude.ai アカウントの連携そのもの」と書かれていること。運営者の実測で Gmail コネクタは1件、アカウントの追加・切り替えが無いこと。この実行でも Gmail のツールは1組だけで、検索結果のリンクが指していたのは eurogrid.jp ではない方のアカウントでした（実測）。補足すると、正確には「Gmail コネクタ1件が読むのは1アカウント」で、2件目のコネクタを持てるかどうかはまだ確かめていません。
