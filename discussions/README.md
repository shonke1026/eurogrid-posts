# discussions/（三者協議の郵便受け）

2026-11-12 作成（運営者の指示）。ユーロ・Claude・チャッピーの三者で話し合うときの置き場所。
運営者が質問を置き、各担当が自分の欄に答え、運営者が決める。

## 運用ルール
- 1つの議論＝1ファイル。名前は `discussions/YYYY-MM-DD-<slug>.md`（slug は半角の英小文字・数字・ハイフン）
- ファイル冒頭に状態行を置く。値は次の4つだけ
  - `状態： Claude回答待ち`
  - `状態： Claude回答済み`
  - `状態： 協議中`
  - `状態： 決定済み`
- 決定後は、状態行のすぐ下に `決定：` の行も置く（決まった内容を1行で）
- セクション構成は次の順で固定
  - `## 素材`
  - `## 質問票（ユーロ）`
  - `## Claude回答`
  - `## チャッピー回答`
  - `## 対照表（ユーロ）`
  - `## 決定`
- 各担当は自分のセクションだけを追記し、他人のセクションは書き換えない
- 公開リポジトリなので、メール宛先・ブラウザ番号・個人情報は書かない（鍵、アカウントの内部ID、OK前の投稿案も書かない。CLAUDE.md の冒頭と同じ）

## 流れ
1. 質問を出す：新しいファイルを作り、`## 素材` と `## 質問票（ユーロ）` を埋めて、状態を `Claude回答待ち` にする。質問には Q1、Q2…と番号を振る
2. Claude が答える：毎朝6:44の定期タスクが、始めに discussions/ を見る。`状態： Claude回答待ち` のファイルがあれば、質問番号に合わせて `## Claude回答` に追記し、状態を `Claude回答済み` に変えてコミットする
   - 回答した日は、朝の報告メールに「discussions の（ファイル名）に回答しました」と1行載せる
   - 質問が無い日は何もしない（記録も残さない）
   - 回答は投稿案づくりを妨げない範囲で。長くなるときは `## Claude回答` に「受付済み」とだけ書き、状態は `Claude回答待ち` のままにして翌朝に答える
3. チャッピーの回答と対照表：`## チャッピー回答` と `## 対照表（ユーロ）` が埋まるあいだ、状態は `協議中`
4. 決定：運営者から決定が伝えられたら、Claude（メインの会話）が状態を `決定済み` にし、`決定：` の行と `## 決定` に内容を書く。本体ルール（CLAUDE.md、platforms/*.md など）への反映は従来どおり、運営者が決めたものをメインの会話で入れる

## ひな形
```markdown
# （議論のタイトル）

状態： Claude回答待ち

## 素材

## 質問票（ユーロ）
- Q1.
- Q2.

## Claude回答

## チャッピー回答

## 対照表（ユーロ）

## 決定
```

決定後の冒頭はこうなる。

```markdown
状態： 決定済み
決定：（決まった内容を1行で）
```
