## 1. コンセプト
- 誰に：MotoGP を日本語で追いたいファンと、これから MotoGP を知る人
- 何を：スペインとイタリアの報道を読み比べ、同じレースの「見え方のちがい」を出典つきで日本語にする
- なぜ Eurogrid か：日本語の発信は結果と翻訳が中心で、両国の論調を並べる場所がない。Eurogrid はその入口になる（キャッチコピー「ふたつの視点、ひとつのグリッド。」）

## 3. フェーズ別ロードマップ

### 段階0：無料で母数と信頼を作る（いま〜2026年内）
- やること
  - Threads のフォロー転換：固定投稿（自己紹介＋代表作＋note）、当たった投稿への自己紹介の返信、プロフィールに note。11/11〜11/24 は Threads のフォローの試し（1日5件まで）
  - Instagram を10投稿まで（当たったネタだけカルーセル。新デザインのテンプレートで）
  - note をレースごとに1本：ポルトガルGP（締切 11/23 10:00）、バレンシアGP（締切 11/30 10:00）で計3本
  - コーナー「欧州から見た🇯🇵」を2回試す（11/24 ごろ、12/1 ごろ）
  - TikTok はリールの転載だけで数字を見る（ポルトガルGP）
- 媒体の役割
  - Threads：拡散と新しい人の入口（本命）
  - X：最速の速報。夜に Threads・Instagram・note へ案内
  - Instagram：当たったネタの図解と保管
  - note：論調比較の本編。いずれの収益の受け皿
  - TikTok：テスト。転載で反応を見るだけ
  - Facebook：ページを作る（2026-11-12 運営者が決定）。Instagram の投稿を流す形で始め、専用の投稿は作らない
  - YouTube：11/30 の週次振り返りで、ポルトガルGPのリールの数字（Instagram と TikTok）を見て、ショートの転載を始めるか決める（2026-11-12 運営者）

### 段階1：最初の収益は Amazon アフィリエイト（段階0の後〜2027年5月）
- 導線を1本にしぼる：SNS（無料）→ note → 記事末の「この回の一冊」
- リンクは note だけ（eurogridnote-22、冒頭の PR 表記と末尾のアソシエイト表記は必ず）。X・Threads・Instagram・TikTok の投稿には貼らない
- 期限：申込（2026-11-10）から180日＝2027年5月9日までに適格販売3件で審査（公式ヘルプで確認済み。5章）
- 自己購入は数に入らない。「審査のために買って」と周りに頼む形は取らない
- オフシーズン（12〜2月）：レースがないぶん、読み物（「MotoGPの本場はどこ？」「なぜ日本では盛り上がらない？」など）を note に積み、各記事に関係のある本を1冊ずつ
- オフシーズン（12〜1月）の読み物で note を10本まで増やす（段階1の必須。5章）
- 2027年2月の時点で販売0件なら：常設の「書籍・入門まとめ」記事を note に作って押し上げる（2026-11-11 決定。note の中だけなので拡大には当たらない。出すのは note が10本に届いてから）
- 審査の条件（登録サイトに10件以上の投稿など。5章）を、3件目の販売より前に満たしておく
- 媒体の役割：段階0と同じ。SNS の各投稿は note への入口として「続きは note」を増やす（リンクは note のトップか記事、Amazon には直接つながない）

### 段階2：note 単品有料のテスト（2027年シーズン開幕期。日程は公式の発表で確かめる）
- 月額ではなく単品。300〜500円で1本から
- 題材は無料の速報では代わりにならない深掘り：両国メディアの評価まとめ（シーズン通しての採点など）、開幕前の展望データパック、など
- 無料：有料は 8：2 を上限。入口になる無料記事は塞がない（レースごとの論調比較は無料のまま）
- 媒体の役割：SNS は無料の速報と要約、note の無料記事が入口、有料は note の一部だけ

### 段階3：メンバーシップとスポンサー（単品有料が2桁売れた後）
- note メンバーシップ（月500円前後を想定。開設の条件はその時点の公式で確かめる）
- フォロワーが千単位になってから、スポンサー・PR の案件（受けるときは必ず PR と書く。ブックメーカー・暗号資産は受けない）
- X・TikTok などの広告収益は条件が遠いので本命にしない。「取れたら追加」

| 段階 | 収益源 | 置き場所 | 本命か |

| 0 | なし | | |

- お金のルールは CLAUDE.md の8（リンクの置き場所、表記、自己購入なし、短縮URLなし）

## 5. 段階ゲート
数字は全部「案」（決めるのは 12/30 の振り返り）。2種類に分ける。
- **必須（出力）**：自分たちで作る量。届かなければ次の段階に進まない
- **観察目標（成果）**：フォロワー数・表示回数など、相手しだいの数字。届かなくても次の段階は止めない。ずれが大きければ、やり方を見直す材料にする

### アソシエイトの審査の条件（公式ヘルプ「申請の審査プロセスについて」で確認、2026-11-11）
- サインアップから180日以内に3回以上の適格販売で、審査が始まる。期限は 2027-05-09（確定）。自分の注文は数に入らない
- 審査では、登録したすべてのサイト（ウェブサイト・SNS）が見られる。どのサイトにもオリジナルの投稿が少なくとも10件いる。ウェブサイトは60日以内に更新されていること。SNS は多くの場合フォロワーなど500以上が目安
- 却下された申請は、その申請としては再審査されない。**3件目の販売が出た時点で審査が始まるので、それまでに登録サイトが条件を満たしている必要がある**
- 審査の目安：登録したサイトは、どれもオリジナルの投稿10件以上（SNS はフォロワー500が目安）
- 登録は note だけ（2026-11-11 に絞った）。SNS を登録し直すのは、その SNS がこの目安を満たし、**かつ** 本採用でその媒体へのリンクを解禁すると運営者が決めたときだけ
- 出典：https://affiliate.amazon.co.jp/help/node/topic/G8TW5AE9XL2VX9VM

## 6. やらないこと
- 早いうちの全面有料化（段階2でも無料：有料は 8：2 まで。入口の無料記事は塞がない）
- SNS の投稿へのアフィリエイトリンク（X・Threads・Instagram・TikTok）
- 審査のための購入のお願い、自分のリンクからの購入
- 広告収益に頼ること
- 根拠のない売上見込みや収入額を書くこと
- 写真・映像・ロゴの無断使用、記事の丸ごと翻訳（CLAUDE.md の6）
