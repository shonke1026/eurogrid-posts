# X（@eurogrid_jp）

共通ルールは CLAUDE.md。ここは X だけのこと。

## 役割
- いちばん速い速報。セッション結果・公式発表を短く出す
- 流れた話題は、夜に Threads・Instagram へ案内する投稿を出す

## 文字数
- X の数え方で 280 以内（日本語・全角は1字＝2、半角英数は1字＝1、URL は長さに関係なく23、絵文字は2）。全角だけなら140字
- 「Motorsport.com」「Crash.net」のように書くとリンク扱いになり23を使う
- 確かめ方：`python3 scripts/check_post.py x "本文"`。投稿画面で tweetButton の aria-disabled が "true" なら超えている

## 形
- 出典 URL は本文に入れない。自分の投稿への返信に「出典：媒体名 URL」。2媒体以上は返信にまとめる
- レースから24時間以内で結果にふれる投稿：本文（結果なし）→ 返信1（中身、⚠️ネタバレ：〜 から始める、視点の1文も）→ 返信2（返信1への返信で出典）
- Eurogridの視点は本文の最後に1文（24時間以内の投稿は返信1の最後）
- ハッシュタグは1〜2個。#MotoGP を毎回つけなくてよい
- 型の例（毎回同じにしない）：
  - 通常ニュース：見出し1行 → 要点 → 視点
  - コメント：「〈短い訳〉」＋状況1行
  - 噂：「⚠️報道ベース」＋要約＋「※公式発表ではありません」
  - 論調比較：🇪🇸 1行／🇮🇹 1行／事実の補足1行

## 画像
- 添付するなら 1600×900：templates/x_image.html。キッカーは速報・比較・解説・結果のどれか。左＝スペイン、右＝イタリア
- 画像に結果を入れるときも、24時間以内は本文と同じくネタバレの決まり（画像はタイムラインで見える）

## 投稿のしかた（Claude用）
- API は有料なので、L5320-note の Chrome から出す
- キーボード入力（type）は日本語の順番が崩れるので使わない
- x.com のタブで javascript_tool から `location.href='https://x.com/intent/post?text='+encodeURIComponent(本文)`（返信は `in_reply_to=ID&` を足す）
- URL入りのときは、intent のページが開いたら入力欄の最後にカーソルを置き、execCommand('insertText',false,' ') で空白を1つ入れる（入力したことになり、カードが読み込まれる。intent で入れただけだとカードを読み込まないまま送れてしまい、投稿のあとにカードが付く）。そのあと2秒おきに15回「カードプレビューを削除」ボタンを探して押す。ボタンが一度も出ないとき・入力欄にカードが残っているときは送らずに止めて運営者に知らせる（11/11 に3回カードが付いて決めた）
- data-testid="tweetButton" の aria-disabled が "true" でないことを確かめてから押す
- x.com/eurogrid_jp で最新の /status/数字 を取り、返信に使う。出したあと、投稿のページでカードが付いていないか見る
- OKのあと続けて出さず、1本ごとに3〜10分（毎回ちがう長さ）あける
- 「すでに同じツイートを送信済み」と出たら、出ているかもしれない。プロフィールで確かめてから出し直す
- 「より多くの機能を利用する」は×で閉じる。本人確認・CAPTCHA・電話番号は進めず運営者に伝える。いいね・フォローは Claude がしない
- 下書きを捨てるので、別のページへ移るときに force: true を使わない
