# 動画の音の決まり（11_video_sound）

リール（縦動画）の音に関する正本。根拠は三者協議「2026-11-15-video-sample-review」の決定（2026-11-15）と「2026-11-15-reel-maker」の制作分担の決定。

## 原則

- 最初から全リールに音を入れる（「試験中は音なし」は廃止）。
- 音は演出であり、必須情報は持たせない。ミュートで再生されても意味が通る構成にする。

## 使う素材（これ以外は使わない）

すべてユーロが全合成で作成した音源で、権利関係はクリーン。出どころはユーロ側の `workspace/eurogrid/music/README.md` に記録。

| 素材 | ファイル | 内容 |
|---|---|---|
| BGM 70年代版 | eurogrid-bgm-70s.wav | ディスコ／ファンク、18秒ループ |
| BGM 80年代版 | eurogrid-bgm-v1.wav | シンセ、18秒ループ |
| BGM 90年代版 | eurogrid-bgm-90s.wav | ユーロダンス、18秒ループ |
| BGM 00年代版 | eurogrid-bgm-00s.wav | トランス、18秒ループ |
| サウンドロゴ | eurogrid-soundlogo-v2-start.wav | スタート音のみ、3.6秒 |
| 切り替わり音 | whoosh | 場面切り替わり用（ユーロの制作パイプライン内蔵） |
| リール用完成音源 | eurogrid-reel-audio-{70s,80s,90s,00s}.wav | BGM＋ロゴのミックス済み |

## 固定とローテーション

- サウンドロゴ（v2）と whoosh は、全リールで完全固定する。音そのもの、入るタイミング、締め画面の視覚ロゴとの組み合わせを変えない。
- BGM だけを投稿順にローテーションする（70s → 80s → 90s → 00s → 70s …）。
- 年代別の効果測定はしない（ローテーションは表現の統一のためで、実験ではない）。

## 音量の階層

- BGM ＜ whoosh ＜ サウンドロゴ の順に大きくする。BGM は文面の読みを邪魔しない音量に抑える。

## 禁止事項

- 放送音源、実車のエンジン音の録音、市販曲、アプリ内ライブラリの音源は使わない。
- 結果によって音を変えない（勝った・負けたで音の明暗を付けない）。
- 選手の発言を声で演じない。声を使う場合は、自作の原稿＋商用 TTS のみ。

## 音なしの例外

- けが・重い事故を扱う回は音なしにする。

## 制作と確認

- 制作分担：文面・監査は Claude、映像の組み立てと音の書き出しはユーロ（2026-11-15-reel-maker の決定）。
- 本番の書き出しは、必ず通しで試聴してから公開工程に回す。
- まとめ場面は3秒以上を確保する（秒数配分の決まりはリールの型に従う）。

## 変更手続き

- この文書の変更は、運営者の決定または三者協議の決定による。
